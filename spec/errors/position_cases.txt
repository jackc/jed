# Shared error Position + Hint cases (spec/design/error-fields.md §10.5, §11).
#
# Every core's error_fields test runs every case and asserts the failing statement's SQLSTATE, its
# structured Position field, and its structured Hint field. The corpus cannot assert a structured
# field, so this one language-neutral file stands in for three hand-mirrored test lists
# (CLAUDE.md §5/§10).
#
# Format: line-oriented, like detail_cases.txt. A case starts at `case: <name>` and ends at the next
# `case:` or end of file. Blank lines and lines starting with `#` are ignored. Directives:
#
#   setup: <sql>     run with the default session; repeatable
#   run: <sql>       the statement that must fail (one statement, through `query`)
#   script: <sql>    instead of `run:`: a multi-statement script run through `execute_script`
#   code: <sqlstate> its SQLSTATE
#   position: <n>    its exact 1-based character Position
#   no-position      instead of `position:`: the Position field must be absent
#   hint: <text>     its exact Hint (to end of line); when no `hint:` line is given, the Hint must be
#                    absent
#
# Expected values are PostgreSQL 18's wherever PostgreSQL rejects the same statement at the same
# token. A case marked `# jed:` has no PostgreSQL equivalent or differs from it by design.
